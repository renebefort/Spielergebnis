# Spielergebnis

Web-App zur Erfassung von Torschützen bei Fußball- und Handballspielen.

## Features

- Tore pro Spieler über +/– Buttons erfassen
- Automatischer Spielstand (Heim : Gast)
- **Handball-Modus:** Multiplikationswertung (Tore × Anzahl Torschützen)
- Ergebnis als Markdown in die Zwischenablage kopieren
- Eingaben bleiben beim Reload erhalten
